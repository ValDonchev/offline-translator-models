# Offline Translator — Model Catalog

Converted [Helsinki-NLP OPUS-MT](https://huggingface.co/Helsinki-NLP) translation
models for the **Offline Translator** app (iPhone, iPad, Mac), packaged in the
Argos-compatible format the app consumes (CTranslate2 int8 + SentencePiece).

- `index.json` — the catalog the app reads (Argos index schema + BLEU/chrF quality scores)
- Release assets — the model packages (`translate-<from>_<to>-<version>.argosmodel`)
